# Security Policy

## Supported versions

Waymark is pre-release. Security fixes are applied to the current development branch and the latest published release once releases exist.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through GitHub's **Report a vulnerability** feature on the repository's Security tab. Do not open a public issue or include credentials, connection strings, tokens, or sensitive database details in a report.

Include:

- the affected commit, version, or branch;
- the provider and database engine involved;
- reproduction steps that use disposable/local resources only;
- impact and any suggested mitigation.

We will acknowledge reports as soon as practical, investigate privately, and coordinate disclosure after a fix or mitigation is available.
